Temporary Secure Text Pad

A scratchpad that never leaves your browser

Jot down something sensitive without it touching a server, a database, or a sync service. It exists only in this tab's memory, and clears when you close it.

0 characters
This is a local-only scratchpad, not a way to share text between devices or people — there's no server behind it, on purpose, so nothing here can leak. It also won't survive a page refresh or a closed tab: that's intentional, not a bug. If you need to send text securely to someone else, use the Text Encryption tool and share the encrypted result plus password through separate channels.

How it works

  1. 01

    Type your text

    It's held only in this page's memory — never written to disk or sent anywhere.

  2. 02

    Set an auto-clear timer

    Optionally have it wipe itself after a period of inactivity.

  3. 03

    Close the tab when done

    Closing or refreshing the tab clears it completely, every time.
